## Versioning and Lifecycle

Never overwrite changed requirements in place. Publish a new version, preserve
the prior version, update the decision log and traceability, and identify the
engineering intake and acceptance result for that exact version.

## Adding Task Packages

Provide Task ID, version, status, sources, scope, out of scope, requirements,
acceptance criteria, dependencies, risks, evidence, prohibited changes,
reviewers, and Documentation Impact.
