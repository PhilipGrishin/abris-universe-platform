## Purpose

Provide navigation for engineering assurance documents that support review,
risk control, compatibility, performance, security, migration, and acceptance.

## Scope

This index routes to assurance document classes. It does not claim that any
threat model, capability, benchmark, checklist, or migration has been completed.

## Owner

AU-AGENT-002 owns navigation, metadata, traceability, consistency, and lifecycle.
Named technical and assurance owners approve the meaning and evidence of each
document.

## Lifecycle

Assurance documents follow their triggering requirement or risk. They must state
method, environment or scope, evidence, limitations, owner, and review triggers.
Stale evidence must not be presented as current.

## Adding Documents

Select the correct category, identify the requirement or risk, provide the
technical owner and approver, record Documentation Impact, link evidence, update
traceability, and complete documentation review.
