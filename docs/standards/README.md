## Purpose

Index approved, reusable engineering standards without duplicating their
normative content.

## Scope

Standards govern recurring engineering practices. They do not replace product
requirements, architecture decisions, or task-specific Technical Designs.

## Current Standards

- [Engineering Documentation Standard](DOCUMENTATION_STANDARD.md) — metadata,
  lifecycle, impact, quality, Handbook, AI-input, and validation rules.

## Owner

AU-AGENT-002 owns index structure and document lifecycle. AU-CODEX-PRIMARY
approves governance standards; AU-AGENT-001 or assigned domain owners approve
technical standards.

## Lifecycle

Standards require explicit approval, versioning, dependency and supersession
records, affected-agent analysis, and adoption evidence.

## Adding Standards

Provide the recurring problem, authority, owner, approver, scope, prohibited
interpretations, compliance checks, migration/adoption plan, Documentation
Impact, and traceability. Reject rules that belong only to one task or invent
unapproved architecture.
