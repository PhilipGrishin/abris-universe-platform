technical content and disposition.

## Lifecycle

Template changes require documentation review and impact analysis for active
RFCs. Individual RFCs follow the RFC Library lifecycle.

## Adding Documents

Create RFCs only for reviewable engineering proposals with known owners and
reviewers. Register the RFC in the library and update traceability.
